# Contributing to Web Security Scanner

Thank you for your interest in contributing to Web Security Scanner! This document provides guidelines and instructions for contributing.

## Code of Conduct

Be respectful and constructive in all interactions.

## How to Contribute

### Reporting Bugs

1. Check existing issues to avoid duplicates
2. Provide clear, detailed description
3. Include steps to reproduce
4. Show expected vs actual behavior
5. Add screenshots if applicable

### Suggesting Enhancements

1. Use clear, descriptive title
2. Provide detailed description
3. List examples of similar features
4. Explain benefits

### Pull Requests

1. Fork the repository
2. Create feature branch (`git checkout -b feature/AmazingFeature`)
3. Commit changes (`git commit -m 'Add AmazingFeature'`)
4. Push to branch (`git push origin feature/AmazingFeature`)
5. Open Pull Request

## Development Setup

```bash
git clone https://github.com/yourusername/web-security-scanner.git
cd web-security-scanner
pip install -r requirements.txt
```

## Coding Standards

- Follow PEP 8 style guide
- Add docstrings to all functions
- Write unit tests for new features
- Keep functions focused and small

## Testing

```bash
python -m pytest tests/
```

## Documentation

- Update README.md for new features
- Add docstrings to all functions
- Include usage examples

## Commit Messages

- Use clear, descriptive messages
- Start with capital letter
- Use imperative mood
- Keep under 50 characters for title
